## Featured Projects

### Ótica Visão de Piabetá

A web application for my father’s optical store, built with C# and ASP.NET Core Razor Pages.

Features include:

- Responsive eyewear catalog with search and filters
- Customer accounts, favorites, and 24-hour frame reservations
- Admin panel for inventory, customers, and sales
- Lens order tracking and financial reports
- PostgreSQL persistence, automated tests with xUnit, and Docker setup

[View repository](https://github.com/kawan-bastos/otica-visao)

### Macro do Butler

A configurable Windows desktop application built with C# and Windows Forms.

Features include:

- Persistent configuration presets
- Primary and secondary profiles
- Customizable values and intervals
- Global keyboard shortcuts
- Custom dark red interface
- Automated Windows builds with GitHub Actions
- Organized architecture with models, services, native integrations, and UI components

[View repository](https://github.com/kawan-bastos/macro-do-butler)
